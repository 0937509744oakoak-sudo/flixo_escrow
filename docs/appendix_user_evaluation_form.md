# แบบประเมินผู้ใช้สั้น (นอกขอบเขตข้อ 1.2.3 ของเล่มปัจจุบัน)

ใช้เมื่อต้องการเก็บข้อมูลเพิ่มก่อนสอบหรืองานต่อ  
กลุ่มเป้าหมายแนะนำ: ผู้ทดลองใช้ระบบ 20–30 คน  
มาตรวัด: Likert 1 = ไม่เห็นด้วยอย่างยิ่ง … 5 = เห็นด้วยอย่างยิ่ง

## ส่วน ก. ข้อมูลทั่วไป
1. บทบาทที่ทดลอง: ผู้ซื้อ / ผู้ขาย / ทั้งสอง  
2. เคยซื้อขายบนโซเชียลมาก่อน: ใช่ / ไม่ใช่  

## ส่วน ข. ความเข้าใจและใช้งาน (Likert 1–5)
1. ข้าพเจ้าเข้าใจว่าเงินถูกกักเก็บที่บัญชีกลางก่อนส่งมอบสินค้า  
2. ข้าพเจ้าเข้าใจสถานะคำสั่งซื้อในแต่ละขั้น  
3. ขั้นตอนซื้อขายใช้งานได้โดยไม่สับสน  
4. หน้าเข้าสู่ระบบแยกจากการยืนยันตัวตนอย่างชัดเจน  
5. ข้าพเจ้ามั่นใจขึ้นเมื่อซื้อขายผ่านระบบนี้เมื่อเทียบกับการโอนตรง  
6. โดยรวมข้าพเจ้าพึงพอใจต่อการทดลองใช้ระบบ  

## ส่วน ค. ปลายเปิดสั้น
1. จุดที่เข้าใจยากที่สุดคืออะไร  
2. สิ่งที่ควรปรับปรุงก่อนใช้งานจริงคืออะไร  

## วิธีสรุปผลในเล่ม (ถ้าเก็บครบ)
- รายงานค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานรายข้อ  
- ไม่สรุปว่าลดการโกงในตลาดจริงจากแบบประเมินนี้เพียงอย่างเดียว  
- แยกชัดว่าเป็นผลสำรวจความเข้าใจ/ความพึงพอใจหลังทดลองใช้ ไม่ใช่ผล accuracy ของโมเดล
