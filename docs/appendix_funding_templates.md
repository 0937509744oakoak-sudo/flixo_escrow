## ภาคผนวก ก — แบบแผนธุรกิจ (Business Model Canvas)

### คำบรรยายใต้ภาพ (แนะนำ)
ภาพภาคผนวก ก แบบจำลองธุรกิจของแพลตฟอร์ม FLIXO ด้วย Business Model Canvas

### วิธีใส่ในเล่ม
1. วาด BMC ใน Canva / Miro / PowerPoint (แนว A4 กว้าง)  
2. Export เป็น PNG  
3. วางใต้หัวข้อภาคผนวก ก เต็มความกว้างหน้า  
4. (ทางเลือก) คัดลอกรูปเดียวกันไปบทที่ 4 เป็นภาพวิเคราะห์แผนธุรกิจ ถ้ามีหัวข้อนั้น

### ข.2 แบบฟอร์มให้คะแนน IOC (ให้ผู้เชี่ยวชาญกรอก)

**คำชี้แจง:**  
+1 = สอดคล้อง  
0 = ไม่แน่ใจ  
−1 = ไม่สอดคล้อง  

**IOC รายข้อ** = ผลรวมคะแนนของผู้เชี่ยวชาญ ÷ จำนวนผู้เชี่ยวชาญ  
**IOC ทั้งฉบับ** = ค่าเฉลี่ยของ IOC รายข้อ  
เกณฑ์ที่ยอมรับโดยทั่วไป: IOC ≥ 0.50 (หรือตามที่อาจารย์กำหนด)
